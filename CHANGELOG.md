# Changelog

## 0.1.0

Initial public version.

- Added per-storage trade locking for visiting ground traders.
- Added support for vanilla stockpile zones.
- Added support for vanilla storage buildings.
- Added compatibility with Adaptive Storage Framework based storage.
- Added fallback support for ThingOwner-based modded storage.
- Added multi-selection toggling.
- Added save-game persistence.
- Added optional gizmo visibility setting.
- Added English and Russian localization.
