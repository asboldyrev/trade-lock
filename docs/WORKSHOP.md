# Steam Workshop

## Title

Trade Lock

## Short description

Exclude selected stockpiles and storage buildings from trade with visiting ground traders.

## Workshop description (BBCode)

[h1]Trade Lock[/h1]

Trade Lock lets you decide which stockpiles and storage buildings may offer their contents to [b]visiting ground traders[/b].

Disable [b]Allow trading[/b] on a storage area or storage building and its contents will no longer appear in the trade window.

[h2]Features[/h2]

[list]
[*]Per-storage trade toggle
[*]Vanilla stockpile zones
[*]Vanilla shelves and other storage buildings
[*]Multi-selection support
[*]Save-game persistence
[*]Adaptive Storage Framework compatibility
[*]English and Russian localization
[/list]

[h2]Compatibility[/h2]

Designed to work with storage that uses RimWorld's normal storage APIs, including Adaptive Storage Framework based mods.

Tested with:
[list]
[*]Vanilla stockpiles
[*]Vanilla storage buildings
[*]Adaptive Storage Framework
[*][sbz] Bookcase
[*][sbz] Fridge
[*][sbz] Neat Storage
[/list]

[b]Harmony is required.[/b]

Adaptive Storage Framework is [b]not[/b] required. Trade Lock simply supports it when installed.

[h2]Scope[/h2]

Trade Lock affects [b]visiting ground traders only[/b].

It intentionally does not change:
[list]
[*]Orbital trading
[*]Player caravan loading
[*]Normal hauling
[*]Recipe ingredient access
[*]Storage filters
[*]Forbidden state
[/list]

[h2]How to use[/h2]

Select a stockpile or storage building and toggle [b]Allow trading[/b].

The lock belongs to the storage, not to the item. If an item is moved from locked storage to unlocked storage, it becomes available for trade again.

[h1]Русский[/h1]

Trade Lock позволяет исключать отдельные складские зоны и хранилища из торговли с [b]наземными торговцами[/b].

Отключите переключатель [b]«Разрешить торговлю»[/b] у склада — и находящиеся в нём предметы перестанут отображаться в окне торговли.

[h2]Возможности[/h2]

[list]
[*]Настройка торговли отдельно для каждого склада
[*]Поддержка обычных складских зон
[*]Поддержка ванильных полок и других хранилищ
[*]Массовое переключение нескольких выбранных складов
[*]Сохранение состояния в сейве
[*]Совместимость с Adaptive Storage Framework
[*]Русский и английский языки
[/list]

[h2]Совместимость[/h2]

Проверено с:
[list]
[*]Ванильными складскими зонами
[*]Ванильными хранилищами
[*]Adaptive Storage Framework
[*][sbz] Bookcase
[*][sbz] Fridge
[*][sbz] Neat Storage
[/list]

[b]Требуется Harmony.[/b]

Adaptive Storage Framework не является обязательной зависимостью.

[h2]Что мод не изменяет[/h2]

Trade Lock влияет только на наземных торговцев и не затрагивает:
[list]
[*]Орбитальную торговлю
[*]Загрузку караванов игрока
[*]Обычную переноску предметов
[*]Использование ингредиентов в рецептах
[*]Фильтры складов
[*]Запрет предметов
[/list]
